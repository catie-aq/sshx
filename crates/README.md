# crates/ — Rust Workspace

This directory contains all Rust crates for the sshx backend.

## Crate Overview

```
crates/
├── sshx-core/     # Shared library: proto definitions, types, IDs
├── sshx/          # CLI binary: the `sshx` command users run
└── sshx-server/   # Server binary: HTTP/WebSocket/gRPC server
```

## Dependency Graph

```
sshx       ──depends on──► sshx-core
sshx-server ──depends on──► sshx-core
```

`sshx-core` is a pure library with no network I/O. It is compiled into both the CLI client and the server.

## Building

```bash
# Build everything
cargo build --workspace

# Build only the server
cargo build -p sshx-server

# Build only the CLI
cargo build -p sshx

# Release build
cargo build --workspace --release

# Cross-compile (see Cross.toml)
cross build --target x86_64-unknown-linux-musl --release
```

## Testing

```bash
cargo test --workspace
```

## Shared Concepts

### Session ID (`name`)
A 10-character alphanumeric string generated by the server on session open.
URL format: `https://<host>/s/<name>#<encryption_key>`

### Encryption Key
A 14-character alphanumeric string generated by the CLI client.
It lives only in the URL fragment — never sent to the server.
Both CLI and browser derive the same AES-128-CTR key via Argon2id KDF.

### Shell ID (`Sid`)
A `u32` counter scoped to one session. Each PTY window has a unique `Sid`.

### User ID (`Uid`)
A `u32` counter scoped to one session. Each browser connection has a unique `Uid`.
